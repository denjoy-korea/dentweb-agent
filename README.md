# DenJOY DentWeb Automation Agent

DentWeb 수술기록을 자동으로 추출하여 DenJOY에 업로드하는 Windows 에이전트입니다.

## 설치

1. [최신 릴리즈](https://github.com/denjoy-korea/dentweb-agent/releases/latest)에서 `dentweb-agent.exe` 다운로드
2. 병원 PC에서 실행
3. DenJOY 앱 설정 화면에서 복사한 에이전트 토큰 입력

## 초기 설정

처음 실행하면 두 단계를 진행합니다:

### 1단계: 토큰 입력
DenJOY 앱 > 설정 > 덴트웹 자동화에서 토큰을 복사하여 붙여넣기

### 2단계: 클릭 좌표 학습
덴트웹 프로그램을 열고, 에이전트가 안내하는 각 단계에서
해당 버튼 위에 마우스를 올린 뒤 Enter를 누릅니다:

1. **경영/통계 메뉴 버튼** - 덴트웹 메인 화면의 통계 메뉴
2. **임플란트 수술통계 탭** - 수술통계 카테고리
3. **조회기간 설정** - 기간 선택 영역
4. **조회 버튼** - 데이터 조회 실행
5. **엑셀 다운로드 버튼** - Excel 내보내기

## 동작 방식

1. DenJOY 서버에 주기적으로 폴링 (기본 30초)
2. 실행 요청 감지 시 학습된 좌표로 덴트웹 자동 클릭
3. 다운로드된 Excel을 DenJOY 서버에 업로드

## 파일 구조

- `config.json` - 서버 URL, Windows 사용자 계정으로 암호화한 토큰 등 (첫 실행 시 자동 생성)
- `dentweb_steps.json` - 클릭 좌표 (학습 모드에서 생성)
- `agent.log` - 실행 로그

## 좌표 재설정

덴트웹 UI가 변경되었거나 좌표가 맞지 않을 경우:
1. `dentweb_steps.json` 파일 삭제
2. 에이전트 재시작
3. 학습 모드가 자동 실행됨

## 요구사항

- Windows 10 이상
- DentWeb 프로그램이 설치되어 있어야 함
- 화면 해상도가 변경되면 좌표 재설정 필요

## 인증정보 보호 (v3.6.3 이상)

에이전트 토큰은 Windows DPAPI로 현재 사용자 계정에 묶어 저장합니다.
이전 버전의 평문 `agent_token`은 업데이트 후 첫 실행에서 원자적으로 암호화됩니다.
암호화나 저장에 실패하면 폴링을 시작하지 않으며 기존 설정 파일을 보존합니다.
PC 또는 Windows 사용자 계정을 바꾸면 앱에서 토큰을 다시 복사해 연결하세요.
클릭 좌표, 이미지 인식, 시작프로그램 등록은 유지됩니다.

릴리즈의 `SHA256SUMS`를 확인할 수 있으며, 자동 업데이트도 체크섬이 일치한 파일만 적용합니다.

## 수술 기록 파일 보호 (v3.6.5 이상)

덴트웹에서 저장한 수술 기록 엑셀은 환자 정보입니다.

- `%LOCALAPPDATA%\DenJOY\private-exports`에 저장합니다. 이 폴더는 현재 Windows 사용자와 SYSTEM만 열 수 있습니다.
- 실행마다 고유한 이름(`denjoy-export-<임의 문자>.xlsx`)으로 저장하므로 덮어쓰기 확인 창이 뜨지 않습니다. 예전 설정의 '예(Y)' 좌표는 쓰지 않습니다.
- 업로드가 성공하든 실패하든 그 파일을 지웁니다. 비정상 종료로 남은 파일은 24시간 뒤 정리합니다.
- v3.6.4까지 쓰던 EXE 옆 `exports` 폴더에는 더 저장하지 않고, 남아 있는 엑셀 파일은 7일이 지나면 정리합니다.
- 덴트웹과 같은 Windows 계정으로 에이전트를 실행하세요. 다른 관리자 계정으로 권한을 올려 실행하면 덴트웹이 이 폴더에 저장하지 못합니다.

## 릴리스

- 태그(`v*`)를 달면 Windows에서 시험·빌드한 뒤 **사전 릴리스**로 게시합니다. 웹 다운로드 링크와 자동 업데이트는 Latest만 받습니다.
- 실제 덴트웹 PC에서 확인한 뒤 `gh release edit <태그> --prerelease=false --latest`로 승격합니다.
- 릴리스 설명은 `RELEASE_NOTES.md`를 씁니다.
