# Windows 에이전트의 자동화 예약 설정

공개 v3.6.5는 에이전트 토큰으로 agent_save_settings를 보냈다. 서버는 에이전트의 상태 조회·실행 선점·결과 보고만 허용하므로 이 설정 저장 경로가 실패한다. 설정 창에서 서버 값을 조회해 표시하고 원장 웹 설정의 변경 위치를 안내하도록 고쳤다. PC의 시작프로그램 및 좌표 설정은 기존 흐름을 사용한다.

2026-11-23 macOS Python 3.11에서 unittest 46개 통과, 6개 건너뜀. 변경 전후 호출부와 서버의 허용 동작을 대조하고, 조회 성공·실패 및 예약 저장 호출 제거를 검토했다. Windows 실기기와 새 EXE는 미검증이다. 공개 v3.6.5 EXE의 SHA-256과 SOURCE_COMMIT은 릴리스 기록과 일치했다. 테스트치과 설정 1행, 마지막 실행 이력 없음, 상태 idle.
